# Desert Liquid Glass 0.1.4

General-purpose Astra-compatible WordPress theme. It owns presentation tokens, the nine approved themes, page canvas, page media, composition modes, responsive/accessibility foundations, site chrome, starter-template surfaces, and WooCommerce presentation.

Renew-48 is optional. This theme contains no membership, funnel, attribution, CRM, booking, payment, or synchronization business logic.

Free is the complete usable public theme. Pro is an explicit unconfigured capability boundary; no licensing endpoint or key format is invented.
