# PCW Renew48 Blocks

Native Gutenberg page and funnel component library for Renew48, ChiroGoAZ, and AromaHMT.

## Editing model

Use **Patterns → Renew48** to start a page. Every pattern is composed from registered `renew48/*` blocks; headings, supporting copy, image URLs, CTA destinations, card data, glass treatment, theme, and interaction settings are editable in Gutenberg. Structural blocks accept inner blocks so a page can be extended without PHP or Elementor.

## Primary blocks

| Need | Block |
| --- | --- |
| Full-screen campaign entry | Cinematic Hero |
| Services / immersive masonry | Immersive Service Galaxy |
| Membership and next-step sequence | Wellness Path Development |
| Long-form editorial conversion | Committed Wellness Flow |
| Referral lifecycle | Referral Program Flow |
| Focused campaign lifecycle | Funnel Flow |
| Social proof / education | Conversion Carousel |
| Privacy explanation before an external action | Modal Trigger / Privacy Handoff |

## Themes and interaction

Each component can use `cobranded`, `chiro`, or `aroma` theme tokens and Default, Ultra Glass, Acrylic Glass, Neon Edge, or Quiet treatment. Reveal motion uses IntersectionObserver and is disabled for reduced-motion preferences. Carousels have visible keyboard-focusable previous/next buttons.

## Boundary

This plugin is presentation and public marketing content only. Never add PHI, clinical intake fields, diagnosis data, membership state, or patient records. Booking and service records stay in the approved provider system; retail checkout stays in WooCommerce. The `Privacy Handoff` block is the intended bridge to those destinations.

## Patterns included

Core: Home, service landing, membership landing, booking, about, contact, blog, FAQ, headers, footers, and privacy modal.

Blueprint: chiropractic and massage service galaxies; service detail; committed wellness; referral; corporate/event/sports; annual contract savings; path quiz; waitlist; gift cards; seasonal wellness; reviews; and an explicitly draft-only insurance-package funnel.
