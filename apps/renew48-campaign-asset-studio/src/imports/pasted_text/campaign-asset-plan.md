# 2. Create a Multi-Channel Asset Matrix

Every campaign concept must be planned as a **content family**, not merely one social graphic.

For each applicable asset, create versions for:

- Email
- Instagram Feed
- Instagram Story / Reel
- Facebook Feed
- Facebook Story
- X / Twitter
- TikTok
- YouTube
- YouTube Shorts
- Google Business Profile
- Yelp
- Snapchat
- LinkedIn

Use the appropriate **native dimensions, aspect ratios, content density, safe areas, CTA treatment, and composition** for each platform rather than simply resizing one master frame.

Identify when a platform does not logically support a particular asset type instead of forcing an inappropriate format.
